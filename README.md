## How to Run

Compile any C program with GCC:

```bash
gcc filename.c -o program
```

Run it on Windows:

```bash
program.exe
```

On Linux/macOS:

```bash
./program
```

## Requirements

- C compiler such as GCC
- VS Code, Code::Blocks, Dev-C++, or another C IDE/editor
- Basic knowledge of C programming
